This project is related to DGA detection.
DGA refers to Domain Generation Algorithm.
It is an cyber attack enabler that Cyber Threat Actors use to control their botnets.
In my project I have experimented 4 deep learning models which are CNN, LSTM, GRU and Transformers.
Finally, I combined the strenghts of these models and tested a hybrid model.
I shared my dataset and python codes as well.
